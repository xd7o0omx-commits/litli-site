# Litli — موقع المتجر

## الملفات
- `index.html` — الصفحة الرئيسية (هوية Apple-style: Noto Kufi Arabic، شريط كريمي، أزرار مسطحة)
- `shop.html` — صفحة التصنيف/الفلترة (محدّثة لنفس الهوية)
- `product.html` — صفحة تفاصيل المنتج (محدّثة لنفس الهوية)

الثلاث صفحات الآن متطابقة بالخطوط والألوان والأزرار — نفس اللوقو، نفس الشريط الكريمي، بدون تأثيرات زجاجية.

## النشر
هذا المشروع مجهّز للرفع مباشرة على Vercel كموقع ثابت (Static Site) — بدون أي إعداد بناء (build) إضافي.
