# Litli — موقع المتجر

## الملفات
- `index.html` — الصفحة الرئيسية (أحدث نسخة، هوية Apple-style)
- `shop.html` — صفحة التصنيف/الفلترة
- `product.html` — صفحة تفاصيل المنتج

## ⚠️ ملاحظة مهمة
`shop.html` و `product.html` بنيتين على الهوية **القديمة** (خط Markazi Text، أزرار زجاجية).
`index.html` صار بالهوية **الجديدة** (Noto Kufi Arabic، شريط كريمي، أزرار مسطحة).

يعني حاليًا لو ضغطتِ من الرئيسية على منتج أو قسم، بيحس الزائر بقفزة تصميم مفاجئة.
**الخطوة الجاية بعد الرفع: نحدّث الصفحتين ليطابقوا هوية الرئيسية.**

## النشر
هذا المشروع مجهّز للرفع مباشرة على Vercel كموقع ثابت (Static Site) — بدون أي إعداد بناء (build) إضافي.
